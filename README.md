# DM Planner Assets

This folder contains all maps and tokens for the DM Planner.

## Structure

```
assets/
├── maps/
│   ├── dungeons/    # Dungeon maps
│   ├── indoors/     # Indoor maps (taverns, houses, etc.)
│   ├── outdoors/    # Outdoor maps (forests, roads, etc.)
│   └── other/       # Other maps
└── tokens/
    ├── monsters/    # Monster tokens
    ├── npcs/        # NPC tokens
    └── other/       # Other tokens (objects, effects, etc.)
```

## How to add new assets

1. Drop image files into the appropriate folder
2. Commit and push to GitHub
3. Users will see new assets automatically when they refresh

## Supported formats

- JPG/JPEG
- PNG
- WebP
- GIF
